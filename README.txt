zozomargiela — alone website

This folder contains the single-page website as index.html.
The cover artwork and audio are embedded directly in the HTML, so no extra assets are required.

To publish:
1. Upload index.html to a public GitHub repository.
2. Enable GitHub Pages in Settings > Pages.
3. Register/own zozomargiela.com with a domain registrar, if you haven't already.
4. In GitHub repository Settings > Pages, set Custom domain to zozomargiela.com.
5. Add the DNS records required by GitHub Pages at your registrar, then enable HTTPS when available.

The domain is not registered or connected automatically by creating these files.
